# VanBanAI public coursework repository

Read README.md for project scope and CONTRIBUTING.md for the delivery contract.
Follow the current user request, not an old roadmap by default. Questions/reviews
are read-only unless the user also asks for changes.

- Verify this repository's branch, status, HEAD and tracked files before editing.
  Do not infer functionality or test results from a separate local prototype.
- At this documentation checkpoint, application code and a package/test toolchain
  are not present. Inspect the tree again before making later status claims.
- One task, one short-lived branch, one coherent tested change at a time.
  Preserve existing staged/unstaged/untracked work. Never reset/clean to appear clean.
- Use explicit staging. No empty/backdated commits, artificial activity or rewritten
  public history. Label imported/adapted code honestly and retain its provenance.
- Never copy secrets, user cases, uploads, raw private data or whole sibling repositories.
- No new paid API calls, source verification/release, deployment, merge or repository
  setting changes without scoped authorization. Push only the authorized branch.
- Use installed skills only when relevant and available in this session; read their
  SKILL.md first. Git workflow for branches/commits; regression testing for changed
  behavior; security review for public data/auth; GitHub operations for PR/CI feedback.
  Do not install plugins or scan every skill for a small task.
- Report actual checks, remaining WIP, commit/branch and remote actions. Documentation
  rules do not prove CI, branch protection, legal correctness or model reliability.
